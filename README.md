# CISC101-Group--PaperSummarizer

This system is a modular pipeline designed to transform a full academic paper into accurate, audience-appropriate section summaries and a unified overview. It also includes two student-designed modules for expert-level and lay-level explanations of the model architecture from “Attention Is All You Need.”
Each module has a clearly defined purpose, inputs, outputs, and internal logic to ensure traceability, non-hallucination, and consistent formatting.
